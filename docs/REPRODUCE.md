## What this release does not cover
- **Regenerating recovery figures needs the candidate pools** (400 samples per test row) and the checkpoint, which
  are not in the repository tree. Without them the figures can only be re-scored, not regenerated.
- **Training and inference** need precomputed ESM-2 per-residue embeddings and AlphaFold structures for the
  accessions, plus the Morgan init table. No script to build the embeddings or fetch the structures is included.
- **Path-portability.** `scripts/` and `src/` are copies of the code as run on the cluster; the only edit is that the cluster login id
  and `/scratch/...` prefixes were replaced by placeholders (`USER`, `/path/to/struct_rxnpred`). They still contain
  absolute paths and `sys.path` setup that expect the original folder layout, so those paths must be edited before running. Nothing beyond the three commands
  above has been executed from this tree.
- **Producers not shipped:** the original split-assignment script (not recovered; the split files are the released artefact) and the exploratory scripts behind the
  negative results (grammar-forced and hybrid decoding, rejection sampling, nucleus sampling).
- `scripts/mcnemar.py` reads a cluster-only file (`hitvecs.json`) and analyses older teacher-forced arms.
